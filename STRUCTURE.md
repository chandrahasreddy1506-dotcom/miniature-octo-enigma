# Project Structure Notes

This project uses a clean Django layout:

- `config/`: Project-level Django configuration.
- `issues/`: Main app (models, views, forms, templates, tests).
- `static/`: Source static files (CSS, JS, images) managed in the repo.
- `media/`: User-uploaded files for local/dev usage.
- `staticfiles/`: Build artifact generated by `collectstatic` (ignored in git).

## Deployment Notes

1. Keep `DJANGO_DEBUG=False` in production.
2. Run migrations before serving traffic.
3. Run `collectstatic` during deployment.
4. Use PostgreSQL via `DATABASE_URL`.
